# lycvvt/mavlink — MoonBit MAVLink v2 Protocol, Microservices & XML Code Generator

`lycvvt/mavlink` 是面向无人机（PX4、ArduPilot）、机器人与地面控制站（QGroundControl）通信的纯 **MoonBit**（Zero FFI）**MAVLink v2 / v1 协议栈、五大微服务状态机（Heartbeat / Parameter / Mission / Command / Timesync）与支持多文件 `<include>` 的官方 XML 自动代码生成器**（内置 18 个标准枚举与 45 条核心飞控消息，76 项测试 100% 通过）。详细工程文档与基准数据请参阅 [`README.md`](./README.md) 与 [`docs/BENCHMARK_AND_BOUNDARIES.md`](./docs/BENCHMARK_AND_BOUNDARIES.md)。
