# lycvvt/mavlink — MoonBit MAVLink v2 Protocol, Microservices, Multi-Link Router & XML Code Generator

`lycvvt/mavlink` 是面向无人机（PX4、ArduPilot）、机器人与地面控制站（QGroundControl）通信的纯 **MoonBit**（Zero FFI）**MAVLink v2 / v1 协议栈、高阶微服务状态机（Heartbeat / Parameter / ParamExt / Mission / Command / Timesync / FTP #110）、多链路防环路由器（`MavRouter`）、QGroundControl `.tlog` 遥测录制回放器与支持多文件 `<include>` 的官方 XML 自动代码生成器**（内置 22 个标准枚举与 60 条核心飞控消息，100 项测试 100% 通过）。详细工程文档与基准数据请参阅 [`README.md`](./README.md) 与 [`docs/BENCHMARK_AND_BOUNDARIES.md`](./docs/BENCHMARK_AND_BOUNDARIES.md)。
